# Hush & Co. — Coffee Shop Ordering System

## Project Overview

Hush & Co. adalah website pemesanan coffee shop modern berbasis web dengan fitur:

- Dine-in menggunakan QR Code meja
- Takeaway order
- Real-time order tracking
- Dashboard staff & admin
- Export laporan PDF & Excel

## Tech Stack

### Frontend
- React.js (Vite)
- Tailwind CSS
- React Router
- Axios

### Backend
- Laravel
- Laravel Sanctum
- Spatie Laravel Permission

### Database
- MySQL

## Roles

### Customer
- Register & Login
- Browse menu
- Checkout
- Track order

### Staff
- Dashboard antrian
- Update status order
- Konfirmasi pembayaran

### Admin
- CRUD menu
- CRUD kategori
- Kelola meja & QR
- Export laporan
